Programs an Encompass 4 reader straight from the browser over USB-serial. No install — Chrome or Edge only. RS-232 model · 9600 8-N-1.
Disconnected
Click Connect, pick the reader's USB-serial / FTDI port. No port listed? Install the FTDI VCP driver. No data after connecting? Swap the Red ↔ Black leads and try the banner test.

Step 1 — Verify the link

Test link just asks the reader its model (#505) and waits for a reply — instant confirmation that both wires are good, no power-cycle. Use Banner test only if Test link gets nothing and you want to isolate the TX vs RX direction.
